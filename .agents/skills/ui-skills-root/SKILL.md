# UI Skills Root - Master Routing & Orchestrator

This skill serves as the central orchestration hub for UI/UX operations in Antigravity.

## Responsibilities
1. **Request Triage**: Classify frontend tasks into visual design, animation/micro-interaction, accessibility, code refactoring, or design system tokens.
2. **Skill Delegation**:
   - For novel layouts and high-fidelity screens: Delegate to `frontend-design`.
   - For auditing and surgical polish of existing screens: Delegate to `improve-ui`.
   - For fluid transitions and physics-based motion: Delegate to `improve-animations`.
   - For state modeling and component hierarchy: Delegate to `improve-react`.
   - For industry-grade palettes, typography, and contrast rules: Delegate to `ui-pro-max`.
3. **Consistency Checking**: Ensure all components adhere to the project's brand guidelines (e.g., KisanVaani Deep Agri-Green `#0B7A3B`, Saffron Orange `#FF8A00`, Slate backgrounds).
