# Improve UI Skill

Specialized in non-destructive interface audits and incremental design enhancements.

## Core Directives
1. **Visual Contrast**: Verify WCAG AA/AAA compliance for text against background surfaces.
2. **Spacing & Alignment**: Align grids, ensure optical centering of icons with text, and normalize padding.
3. **Responsive Breakpoints**: Check desktop (1280px+), tablet (768px-1024px), and mobile (<640px) rendering.
4. **Interactive States**: Guarantee hover, focus-visible, active, and disabled states are clearly styled.
