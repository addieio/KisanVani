# UIUX Pro Max Design System Skill

Provides deep domain-specific design intelligence, color harmonies, and typography pairings tailored for B2B AgriTech and commerce platforms.

## KisanVaani "Mandi-Direct" Ruleset:
- **Primary Color:** `#0B7A3B` (Deep Agri-Green)
- **Primary Hover:** `#096330`
- **Primary Subtle:** `#E8F5E9` (Green-50 tint for active states and badges)
- **Accent Color:** `#FF8A00` (Saffron Orange for bids, badges, and alerts)
- **Accent Subtle:** `#FFF4E6`
- **Surface Colors:**
  - Base canvas: `#F8FAFC` (`bg-slate-50`)
  - Card canvas: `#FFFFFF` (`bg-white`)
  - Border: `#E2E8F0` (`border-slate-200`)
  - Muted text: `#64748B` (`text-slate-500`)
  - Heading text: `#0F172A` (`text-slate-900`)
- **Typography Pairing:**
  - Headings & Body: Inter (`https://fonts.google.com/specimen/Inter`)
  - Data / Metrics: Tabular numeric styling (`font-feature-settings: 'tnum'`)
