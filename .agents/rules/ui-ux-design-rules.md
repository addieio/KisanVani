# KisanVaani "Mandi-Direct" UI/UX Design System Rules

## Visual Foundations
- **Color Tokens**:
  - Primary: `#0B7A3B` (Agri-Green)
  - Primary Hover: `#096330`
  - Accent / Bids: `#FF8A00` (Saffron Orange)
  - Background Canvas: `#F8FAFC` (`bg-slate-50`)
  - Surface Card: `#FFFFFF` (`bg-white`)
  - Border: `#E2E8F0` (`border-slate-200`)
  - Text Primary: `#0F172A` (`text-slate-900`)
  - Text Muted: `#64748B` (`text-slate-500`)

## Escrow Status Colors
- `ACCEPTED`: Blue (`bg-blue-50 text-blue-700 border-blue-200`)
- `IN_TRANSIT`: Saffron / Amber (`bg-amber-50 text-amber-700 border-amber-200`)
- `HANDOVER_PENDING`: Purple (`bg-purple-50 text-purple-700 border-purple-200`)
- `PAID`: Emerald (`bg-emerald-50 text-emerald-700 border-emerald-200`)

## Typography & Micro-interactions
- Inter typography with tight optical sizing
- Smooth micro-interactions via Framer Motion
- Tabular figures for weights and rupee currency formatting
